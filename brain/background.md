# Project background

`setup-xcode` is a GitHub Action for switching between pre-installed versions of Xcode on macOS runner images, now fully powered by Node.js 24.

## Goals
- Fast and reliable Xcode version switching in GitHub Actions workflows.
- Broad compatibility across macOS runner images (macOS 14, 15, 26).
